# 🎓 Student Grade Manager (Python + CustomTkinter)

A simple but modern desktop GUI application to manage student records, built using Python, CustomTkinter, and JSON for persistent storage.

---

## 🚀 Features

- Add student name and grade
- Delete student records
- View all students in real-time UI
- Calculate average grade
- Find highest scorer
- Data stored permanently using JSON
- Dark mode modern UI (CustomTkinter)

---

## 🛠️ Tech Stack

- Python 🐍
- CustomTkinter 🎨
- JSON (for storage) 📁

---

## 📸 UI Layout

The app uses a two-panel dashboard design:

### 🟣 Left Panel
- Input fields for Name & Grade
- Action buttons:
  - Add Student
  - Delete Student
  - Show Average
  - Show Highest Grade

### 🟣 Right Panel
- Live student list display
- Results/statistics display

---

### 💾 How Data Works
When you add a student → data is stored in students.json
When you delete a student → data is removed from JSON
When app starts → data is loaded automatically from JSON
